# Simple Interest Calculator

A simple Bash-based calculator that calculates simple interest using the principal amount, annual rate of interest, and time period.

## Formula

Simple Interest = (Principal × Rate × Time) / 100

## Inputs
- **Principal:** The initial amount of money.
- **Rate:** Annual rate of interest in percentage.
- **Time:** Time period in years.

## How to Run

```bash
bash simple-interest.sh
```

Enter the principal amount, rate of interest, and time period when prompted.

## Output

The calculator displays the simple interest calculated from the provided values.
